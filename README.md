# Foodiegram

Foodiegram is a short-video based food discovery platform that helps users explore restaurants through reels, discover popular dishes, compare prices across delivery apps, and save food items they want to try later.

The platform combines social media style food discovery with practical features like restaurant details, menu insights, and smart food exploration.

---

## Features

• Short-video style food discovery feed
• Restaurant profiles with food highlights
• Save dishes to wishlist/cart from reels
• Compare food prices across delivery platforms
• Explore trending restaurants and dishes
• Mobile-friendly and responsive UI

## Installation

Clone the repository

git clone https://github.com/NageshShankar/FoodieGram

Navigate into the project

cd foodiegram-frontend

Install dependencies

npm install

Run the development server

npm run dev

The application will start on

http://localhost:3000
